# Third-party notices

mustr is built on Zed (its licenses are in Zed's own files) and runs on T3 Code. This file lists
what mustr's own crates copy from other projects.

## T3 Code's editor icons

`mustr-crates/mustr_ui/assets/app_icons/` holds the icons T3 Code's app draws for the editors its
Open in picker offers (Cursor, Trae, Kiro, VS Code, VS Code Insiders, VSCodium, Zed, Antigravity,
the JetBrains IDEs, Finder and File Explorer), converted from T3's
`apps/web/src/components/Icons.tsx` and `JetBrainsIcons.tsx` (T3 Code 0.1.3) into SVG and PNG
files. The logos are their owners' trademarks; mustr shows them only to name the program a
button opens.
